# xcanbus

xcanbus 是一款面向汽车电子研发、台架测试、诊断刷写和现场问题定位的 Windows 桌面工具。产品围绕 CAN、ISO-TP、UDS 与 DoIP 诊断场景，提供从通信配置、诊断服务管理、可视化流程编排到执行监控和报文分析的一体化工作流。

本仓库用于发布可运行程序包，不包含工程源代码及内部技术实现资料。

## 产品定位

xcanbus 主要服务于 ECU、域控制器及车辆电子系统的研发和测试工作，适合以下用户：

- ECU 和域控制器软件研发工程师。
- 台架、整车及自动化测试工程师。
- 诊断与刷写工具链开发人员。
- 项目交付、问题分析和现场支持人员。

## 核心能力

### 可视化诊断流程

- 使用节点和连线组织诊断服务，直观表达服务顺序和通路关系。
- 支持诊断流程的创建、编辑、复制、保存、加载和重复执行。
- 支持流程组管理，可将不同 ECU、任务或测试阶段分别组织。
- 支持自动执行流程并展示节点进度、结果和异常状态。
- 适合组织会话切换、安全访问、例行程序、数据传输和刷写序列。

### CAN、ISO-TP 与 UDS

- 提供 CAN 设备、通道、波特率及收发参数配置。
- 提供 ISO-TP 分段传输及常用时序、流控和填充参数配置。
- 提供 UDS 诊断地址、P2/P2*、S3 等参数配置。
- 支持 CAN、TP、UDS 通路组合和多通路管理。
- 支持常规诊断、数据读取与写入、例行程序、安全访问及刷写流程。

### DoIP 诊断

- 支持基于以太网的 DoIP 通信配置与诊断交互。
- 可用于车辆发现、路由激活和 UDS over DoIP 场景。
- 可与可视化诊断流程配合使用。

### DBC 数据能力

- 支持加载 DBC 文件并浏览消息、信号和枚举定义。
- 支持 CAN 报文与 DBC 消息匹配及信号物理值解析。
- 支持 DBC 消息编码并通过选定 CAN 通路发送。
- 支持原始 Trace、符号化消息和解码信号联合展示。
- 支持按消息名、信号名和信号值过滤及 CSV 导出。
- 提供 Signal Watch 和轻量实时曲线，便于观察关键变量变化。

### Trace 与问题定位

- 提供 CAN 层收发 Trace，展示时间、方向、CAN ID、长度和数据。
- 提供 UDS 请求、响应、耗时和执行结果追踪。
- 支持按 CAN ID 分组、原始与符号化视图切换和数据导出。
- 便于定位无响应、超时、负响应、参数错误和流程中断。

### 工程数据交换

- 支持通过 Excel 导入和导出诊断服务及流程数据。
- 支持保存可复用的通路和流程配置。
- 适合团队评审、台架复现、版本归档和问题材料整理。

## 产品特色

- **流程可视化**：将复杂诊断序列转化为可观察、可编辑和可复用的流程图。
- **通路与流程协同**：同一套流程可以结合不同诊断通路组织工程任务。
- **原始数据与语义联动**：将 CAN 原始报文、DBC 信号和诊断执行状态放在同一工作流中分析。
- **面向真实工程场景**：兼顾单服务调试、自动化序列、刷写执行和问题复现。
- **本地桌面运行**：工程配置、DBC、Trace 和诊断数据默认在本机处理。

## 典型应用场景

- ECU 基础诊断功能验证。
- DID 读取、写入及例行程序测试。
- 诊断会话切换和安全访问验证。
- 0x34、0x36、0x37 等刷写服务流程组织。
- 多 ECU、多通道和多通路台架测试。
- CAN 或 DoIP 诊断通信联调。
- DBC 信号监控、报文分析和故障复现。
- 诊断流程评审、交付与回归验证。

## 运行环境

- Windows 10/11 x64。
- 支持的 CAN 适配器及对应厂商驱动。
- 首次运行需要联网完成许可证校验。
- 若系统提示缺少 `MSVCR100.dll`，可安装 `_bin/vcredist_x64_2010_sp1.exe` 后重试。

硬件型号、CAN FD、DoIP 和具体诊断服务的可用范围取决于当前版本、设备驱动及目标 ECU 配置。

## 快速开始

1. 下载或克隆本仓库，并保持 `_bin` 目录结构完整。
2. 安装所用 CAN 适配器的官方驱动。
3. 运行 `_bin/xcanbus.exe`。
4. 根据测试目标配置 CAN、TP、UDS 或 DoIP 通路。
5. 创建或导入诊断服务流程，确认通路连接后开始执行。
6. 通过 Trace、DBC 解码和执行状态观察结果。

不要在程序运行期间单独替换 DLL、配置文件或可执行程序，以免形成版本不一致的运行包。

## 使用提示

- 仅在获得授权的车辆、ECU 和台架环境中使用。
- 刷写和安全访问可能改变 ECU 状态，执行前应确认电源、总线、镜像和回滚方案。
- 对外分享截图、Trace、DBC 或日志前，请先移除客户名称、车辆信息、诊断数据、内网地址和访问凭据。
- 硬件驱动及随包第三方组件的权利归各自权利人所有，其使用条件以对应许可为准。
